# 5. 레이아웃 결함

## 5-1. p8 텍스트 겹침 ⚠️ 신규 발견 · 치명적

p8 `DESIGN CONCEPT` 영역의 **CLIMBING 설명문 한가운데에 `STORY CONCEPT`라는 텍스트가 끼어 있습니다.**

```
현재 상태:
  CLIMBING  도전하는 놀이
  오르기와 매달리기로
  STORY CONCEPT          ← 삭제되지 않은 중복 텍스트 박스
  성취감과 자신감을 키우는 공간
```

편집 중 삭제하지 않은 텍스트 박스가 본문 위에 겹쳐 있는 것으로 보입니다.
**인쇄 시 글자가 겹쳐 출력될 위험이 있습니다.**
→ 중복 `STORY CONCEPT` 텍스트 박스를 삭제하고, CLIMBING 설명문을 2줄로 복원할 것.

## 5-2. p8 DESIGN CONCEPT 항목 수 불일치

| 페이지 | DESIGN CONCEPT 항목 |
|---|---|
| p5 (1BL) | NATURE / VERTICAL PLAY / LANDMARK — **3개** |
| **p8 (2-1BL)** | **NATURE** / CLIMBING / MOVEMENT / ACTIVE FLOW — **4개** |
| p11 (2-2BL) | MARINE STORY / MARINE SYMBOL / PLAY FLOW — **3개** |

p8의 `NATURE` 블록만 DESIGN CONCEPT 박스 **바깥 우측 상단에 이탈 배치**되어 있습니다.
→ **`NATURE` 블록을 삭제하고 3개 체계로 통일할 것.** (7번 항목의 키워드 재설계와 연동)

## 5-3. p5 마스터플랜 번호 누락

p5 마스터플랜 범례는 7개 항목인데, **도면에 4번·6번 번호 표기가 확인되지 않습니다.**
→ 3개소(p5·p8·p11) 전 도면의 **범례 ↔ 도면 번호 1:1 대조** 후 누락 번호 보완.

## 5-4. 기구 중복 배치

**`Tree Frog's Springer`가 1BL(p5·p6)과 2-2BL(p11)에 중복 배치**되어 있습니다.
제안서 전체가 "세 개의 서로 다른 놀이경험"을 주장하는데 동일 기구가 겹칩니다.
→ p11 4번 항목을 **해양 테마 기구로 교체.** **[확인요망]** 본사에 동급 대체안 요청.

## 6-2b. A/S 대응 — 원안 p2 블록을 살린다 ★ 새로 만들지 않는다

**외산 A/S 대응은 원안 p2 하단에 이미 있다.**

```
현행:  정식 파트너십       제조사 직거래         지속적인 기술지원
      프랑스 본사와의      정식 수입 절차를      프랑스 본사의 기술지원과
      독점 공급 계약       통한 안정적 공급      부품 수급 연계
```

외산 제안에서 가장 중요한 블록인데 지금은 작게 들어가 있다.
**틀은 그대로 두고 크기를 키운 뒤, 각 칸에 구체적인 사실만 채운다.**

| 칸 | 채울 내용 |
|---|---|
| 정식 파트너십 | 독점 공급 계약 (체결 시점 · 계약 형태) |
| 제조사 직거래 | 중간 유통 없음 → 원가 · 납기 · 부품 경로가 단일 |
| 지속적인 기술지원 | **국내 상시재고 품목 [확인요망]종**<br>**본사 발주 소요 [확인요망]주**<br>기술지원 연락 체계 |

# 7. ★ 컨셉 키워드 체계 재설계 — 가장 중요

## 7-1. 현재 진단 — 키워드가 이중으로 운영되며 중복·충돌

각 블록이 **개요 페이지용 키워드**와 **상세 페이지용 키워드**를 따로 쓰고 있어,
심사위원은 한 블록당 6개의 키워드를 만나지만 실제로는 절반이 같은 말입니다.

| 블록 | 개요(p3·컨셉장) | 상세(마스터플랜장) | 문제 |
|---|---|---|---|
| 1BL | WOW / LANDMARK / VERTICAL PLAY | NATURE / VERTICAL PLAY / LANDMARK | **2개 중복** |
| 2-1BL | p3 `MOVEMENT` ↔ p7 `ACTIVE PLAY` | CLIMBING / MOVEMENT / ACTIVE FLOW | **같은 자리에 다른 단어 + 2개 중복** |
| 2-2BL | STORY / SYMBOL / IMAGINATION | MARINE STORY / MARINE SYMBOL / PLAY FLOW | **2개 중복** |

추가 문제: **`WOW 강렬한 첫인상`은 자화자찬형 키워드**입니다.
강렬한지 아닌지는 제안자가 아니라 심사위원이 판단합니다. 제안서에 쓰면 오히려 감점 요인입니다.

## 7-2. 해결 — 이미 가지고 있는 것을 승격시킨다

각 블록에는 이미 **STORY CONCEPT 3단계**가 있습니다. 이것이 가장 기억에 남습니다.
**별도 키워드를 만들지 말고, 스토리 3단계를 그대로 디자인 키워드로 승격**하십시오.

| 블록 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| **1BL** FOREST CASTLE | **NATURE**<br>자연을 만나다 | **CLIMB**<br>탐험하며 오르다 | **HORIZON**<br>넓은 세상을 만나다 |
| **2-1BL** CHALLENGE CASTLE | **CHALLENGE**<br>도전하다 | **MOVE**<br>움직이다 | **DISCOVER**<br>발견하다 |
| **2-2BL** OCEAN CASTLE | **SAIL**<br>항해하다 | **MEET**<br>만나다 | **IMAGINE**<br>상상하다 |

**적용 방법**
- 개요 페이지(p3)와 컨셉 페이지의 우상단 아이콘 3개 → 위 키워드로 교체
- 마스터플랜 페이지의 DESIGN CONCEPT 3개 → **동일 키워드 반복** (다른 단어를 쓰지 말 것)
- `WOW` / `ACTIVE PLAY` / `PLAY FLOW` / `LANDMARK` / `SYMBOL` → 삭제

> **한 블록당 키워드 6개 → 3개.** 반복되면 각인되고, 흩어지면 사라집니다.

## 7-3. 이 구조가 만드는 결정적 한 줄

세 블록의 **3단계 키워드**를 나란히 놓으면 이렇게 됩니다.

```
HORIZON  ·  DISCOVER  ·  IMAGINE
```

**세 개의 캐슬이 모두 마지막 단계에서 아이를 '더 넓은 곳'으로 보냅니다.**

현행 제안서는 *"하나의 디자인 언어로 연결된다"*고 **주장만 하고 증명하지 않습니다.**
이 한 줄이 그 증명입니다. p3 하단에 반드시 삽입하십시오.

```
세 개의 캐슬은 모두, 세 번째 걸음에서 아이를 더 넓은 곳으로 보냅니다.
HORIZON · DISCOVER · IMAGINE — 놀이의 끝은 언제나 확장입니다.
```

## 7-4. ★ 제품명의 어원 — 심사위원을 사로잡을 카드

이것이 **국내 업체가 절대 쓸 수 없는 문장**이며, 외산을 선택할 명분이 됩니다.

| 제품 | 어원 | 삽입할 문장 |
|---|---|---|
| **Kanopé** (1BL) | 프랑스어 `canopée` = **숲의 지붕**(임관층) | *"Kanopé는 프랑스어로 '숲의 지붕'입니다.<br>아이는 숲의 지붕까지 오릅니다."* |
| **Kairn** (2-1BL) | `cairn` = 산길에 쌓아올린 **돌탑 이정표** | *"Kairn은 산길에 쌓아올린 돌탑입니다.<br>먼저 오른 사람이 다음 사람을 위해 남긴 표식."* |
| **Aquatica** (2-2BL) | 라틴어 `aqua` = **물** | *"Aquatica, 물에서 시작된 이름."* |

**삽입 위치:** 각 블록 컨셉 페이지(p4·p6·p8)의 제품 소개 문장 첫 줄.

> **효과:** *"프랑스 제품을 수입한 것이 아니라, 이름의 뜻까지 이해하고 골랐다"*는 인상.
> 심사위원이 제안서를 덮은 뒤에도 기억하는 것은 수치가 아니라 이런 문장입니다.
>
> ⚠️ **[확인요망]** 본사에 제품 네이밍 의도를 확인한 뒤 확정할 것. 어원 해석이 본사 의도와
> 다를 경우 문장을 수정해야 합니다.

## 7-5. 지역 서사 연결 — "왜 광주에 바다인가"에 대한 답

**2-2BL 해양 테마는 내륙도시 광주와 연결고리가 약합니다.** 심사에서 반드시 나오는 질문입니다.
제품은 그대로 두고 **스토리만 잇습니다.**

```
무등산에서 시작한 물이  →  광주천을 지나  →  영산강으로  →  그리고 바다로

1BL의 숲에서 시작해 2-2BL의 바다에서 끝나는, 하나의 여정입니다.
```

**삽입 위치:** p3 3개소 개요 페이지.
→ 지역성 방어와 3개소 연결 서사가 **한 번에 해결**됩니다.

> ⚠️ **[확인요망]** 현장 인근 지형·조망축은 실제 대지 조건 확인 후 기재할 것. 틀리면 역효과입니다.

## 7-6. ★ 「아시아 최초」 — 유지하되, 근거로 강화

**이 제안서의 가장 강력한 차별점입니다. 삭제하거나 완화하지 마십시오.**
다만 현재는 **주장만 있고 근거가 없습니다.** 주장은 근거가 붙을 때 강해집니다.

현행 문구:
> *"본 제안 제품의 아시아 최초 도입을 통해, 광주중앙만의 차별화된 시그니처 놀이터를 구현합니다."*

### ① 근거 한 줄 추가 — 배너 하단 소형 텍스트

```
J56011 Kanopé · J6102 Kairn · Aquatica — 3개 기종 모두 아시아 미설치 기종
Proludic France 확인 [확인요망]
```
→ 품번을 명시하는 순간 **"마케팅 수사"가 "검증 가능한 사실"로 바뀝니다.**

### ② 본사 실적과 결합 — 숫자가 클레임을 떠받친다

```
55개국 150,000개소.
그러나 아시아에는, 아직 없습니다.

광주중앙이 처음입니다.
```

현재 p2의 「55개국 150,000개소」와 p3의 「아시아 최초」가 **따로 놀고 있습니다.**
두 숫자를 한 문장으로 묶으면 서로를 떠받칩니다.
*'15만 개소를 지은 회사가 아시아에는 아직 안 지었다'* — 이 대비가 희소성을 만듭니다.

### ③ 노출 위치 확대 — 현재 p3 배너 한 곳뿐

| 위치 | 문구 |
|---|---|
| p1 표지 배지 | `… · 아시아 최초` |
| p3 배너 | **ASIA'S FIRST** / 아시아 최초 도입 (현행 유지 + 근거 추가) |
| p4 · p6 · p8 푸터 | 아시아 최초 도입 기종 |

→ **첫 장에서 박고, 세 번 반복합니다.**

### ④ 방어는 헤드라인이 아니라 뒤에서

"검증 안 된 것 아닌가"라는 우려는 심사에서 반드시 나옵니다.
그러나 **그 방어를 배너에 붙이면 클레임이 약해집니다.**

```
공격은 앞에(p3), 방어는 뒤에(p11).
```

→ p11 Q&A 5번 행이 이미 그 역할을 합니다:
*"유럽 [확인요망]개소 · [확인요망]년 운영 / 제품은 검증됐고, 아시아에 없을 뿐입니다"*

### ⑤ 분양 카피 연결

```
광주에 없던 놀이터, 아시아에 없던 놀이터.
```
→ 상품기획 담당이 바로 쓸 수 있는 문장입니다. PT 구두 전달용.

# 8. 슬로건 · 워딩 통합

## 8-1. 현재 진단

슬로건이 **7개** 난립합니다.
`More Than Play` / `Play for Generations` / `Play for a Better Tomorrow` /
`Play the Tomorrow` / `Not just imported...` / `Different Experiences...` / `Asia First`

## 8-2. 단일 축으로 통합

```
              THE FIRST CASTLE
         아이가 처음 갖는, 자신만의 캐슬

       프랑스가 설계하고, 롯데캐슬이 완성합니다.

        THREE CASTLES, ONE LOTTE CASTLE
```

## 8-3. 3개소 네이밍 교체

| 블록 | 변경 전 | 변경 후 |
