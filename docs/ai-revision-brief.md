## ■ AI에게 주는 지시

당신은 프랑스 놀이시설 브랜드 **Proludic**의 한국 독점 수입사가 **롯데건설**에 제출하는
「광주중앙 1BL·2-1BL·2-2BL 조경놀이(외산) 디자인공모」 제안서를 교정·보강하는 작업을 맡았습니다.

원안은 **Proludic 프랑스 본사가 제작**한 것이라, 제품과 디자인은 완성도가 높지만
**발주처(롯데캐슬)와 지역(광주)에 대한 연결이 비어 있습니다.** 그 두 가지를 채우는 것이 이번 작업의 핵심입니다.

### 절대 규칙

```
1. 제출 매수 11장 고정. 페이지를 늘리지 마라. 별첨·부록도 안 된다.
2. 확인이 필요한 숫자는 쓰지 마라. 빈칸이나 [확인요망]으로 남기지도 마라.
   그런 내용은 이번 수정본에서 아예 빼고 간다.
   (납기 주수, 인증 소요기간, 재고 품목 수, 유럽 실적 개소수 등)
3. 제품명·품번·치수·소재는 본 문서에 명시된 것 외에는 건드리지 마라.
4. 롯데건설·Proludic 상표와 로고 형태는 바꾸지 마라.
5. 「아시아 최초」는 유지한다. 빼거나 완화하지 마라.
6. 책임·보증·손해배상 문구는 넣지 마라.
   인증 통과, 납기 준수, 하자보수는 납품자가 계약상 당연히 지는 의무이지
   제안 조건이 아니다. 약속하는 문장 대신 절차·체계 같은 사실만 써라.
7. 수정 결과는 "변경 전 → 변경 후" 대조표와 함께 제출하라.
```

# 5. 레이아웃 결함

## 5-1. p8 텍스트 겹침 · 치명적

p8 `DESIGN CONCEPT` 영역의 **CLIMBING 설명문 한가운데에 `STORY CONCEPT`라는 텍스트가 끼어 있다.**

```
CLIMBING  도전하는 놀이
오르기와 매달리기로
STORY CONCEPT          ← 삭제되지 않은 중복 텍스트 박스
성취감과 자신감을 키우는 공간
```

편집 중 삭제하지 않은 텍스트 박스가 본문 위에 겹친 것으로 보인다.
**인쇄 시 글자가 겹쳐 출력될 위험이 있다.** 중복 박스를 삭제하고 설명문을 2줄로 복원할 것.

## 5-2. p8 DESIGN CONCEPT 항목 수

| 페이지 | 항목 |
|---|---|
| p5 (1BL) | NATURE / VERTICAL PLAY / LANDMARK — 3개 |
| **p8 (2-1BL)** | **NATURE** / CLIMBING / MOVEMENT / ACTIVE FLOW — **4개** |
| p11 (2-2BL) | MARINE STORY / MARINE SYMBOL / PLAY FLOW — 3개 |

p8의 `NATURE` 블록만 박스 **바깥 우측 상단에 이탈 배치**되어 있다.
→ 삭제하고 3개 체계로 통일. (7번 키워드 재설계와 연동)

## 5-3. 도면 번호

# 7. ★ 롯데와 광주를 넣는다 — 이번 작업의 핵심

원안은 본사 제작물이라 **어느 현장에 내도 되는 제안서**로 읽힌다.
발주처와 지역을 채우는 것이 1차 수정의 목적이다.

## 7-1. 슬로건 통합 — 7개를 1개로

현행: `More Than Play` / `Play for Generations` / `Play for a Better Tomorrow` /
`Play the Tomorrow` / `Not just imported…` / `Different Experiences…` / `Asia First`

전부 본사 문구이고, **어디에도 '롯데캐슬'이 놀이터와 결합되어 있지 않다.**

```
              THE FIRST CASTLE
         아이가 처음 갖는, 자신만의 캐슬

       프랑스가 설계하고, 롯데캐슬이 완성합니다.

        THREE CASTLES, ONE LOTTE CASTLE
```

## 7-4. 지역 서사 — "왜 광주에 바다인가"

2-2BL 해양 테마는 내륙도시 광주와 고리가 약하다. 심사에서 반드시 나오는 질문이다.
제품은 그대로 두고 **스토리만 잇는다.**

```
무등산에서 시작한 물이  →  광주천을 지나  →  영산강으로  →  그리고 바다로

1BL의 숲에서 시작해 2-2BL의 바다에서 끝나는, 하나의 여정입니다.
```

**삽입 위치:** p3 3개소 개요 페이지.
→ 지역성 방어와 3개소 연결 서사가 한 번에 해결된다.

> 무등산·광주천·영산강은 광주의 일반 지리이므로 그대로 써도 된다.
> **단, 현장에서 무등산이 보인다는 식의 조망축 표현은 쓰지 말 것.** (현장 확인 전)

# 8. ★ 컨셉 키워드 재설계

## 8-1. 진단 — 블록당 6개인데 절반이 중복

| 블록 | 개요(p3·컨셉장) | 상세(마스터플랜장) | 문제 |
|---|---|---|---|
| 1BL | WOW / LANDMARK / VERTICAL PLAY | NATURE / VERTICAL PLAY / LANDMARK | 2개 중복 |
| 2-1BL | p3 `MOVEMENT` ↔ p7 `ACTIVE PLAY` | CLIMBING / MOVEMENT / ACTIVE FLOW | **같은 자리에 다른 단어** + 2개 중복 |
| 2-2BL | STORY / SYMBOL / IMAGINATION | MARINE STORY / MARINE SYMBOL / PLAY FLOW | 2개 중복 |

`WOW 강렬한 첫인상`은 자화자찬형 키워드다. 강렬한지는 심사위원이 판단한다.

## 8-2. 해결 — STORY CONCEPT 3단계를 키워드로 승격

각 블록에 이미 있는 것을 쓴다. 새로 만들지 않는다.

| 블록 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| **FOREST CASTLE** | **NATURE**<br>자연을 만나다 | **CLIMB**<br>탐험하며 오르다 | **HORIZON**<br>넓은 세상을 만나다 |
| **CHALLENGE CASTLE** | **CHALLENGE**<br>도전하다 | **MOVE**<br>움직이다 | **DISCOVER**<br>발견하다 |
| **OCEAN CASTLE** | **SAIL**<br>항해하다 | **MEET**<br>만나다 | **IMAGINE**<br>상상하다 |

- 개요·컨셉 페이지 아이콘 3개 → 위 키워드로 교체
- 마스터플랜 DESIGN CONCEPT 3개 → **동일 키워드 반복** (다른 단어를 쓰지 말 것)
- `WOW` / `ACTIVE PLAY` / `PLAY FLOW` / `LANDMARK` / `SYMBOL` → 삭제

## 8-3. 결정적 한 줄

```
HORIZON  ·  DISCOVER  ·  IMAGINE
```

**세 개의 캐슬이 모두 마지막 단계에서 아이를 '더 넓은 곳'으로 보낸다.**

원안은 *"하나의 디자인 언어로 연결된다"*고 **주장만 하고 증명하지 않는다.**
이 한 줄이 그 증명이다. p3 하단에 삽입할 것.

```
세 개의 캐슬은 모두, 세 번째 걸음에서 아이를 더 넓은 곳으로 보냅니다.
HORIZON · DISCOVER · IMAGINE — 놀이의 끝은 언제나 확장입니다.
```
