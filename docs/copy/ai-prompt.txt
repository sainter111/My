첨부한 「AI 수정 의뢰서」대로 제안서를 수정해라.

■ 상황
프랑스 놀이시설 브랜드 Proludic의 한국 독점 수입사가
롯데건설에 내는 「광주중앙 1BL·2-1BL·2-2BL 조경놀이(외산) 디자인공모」
제안서다. 현행 11장. 경쟁 PT다.

원안은 Proludic 프랑스 본사가 만든 것이라
제품과 디자인은 좋지만 발주처(롯데캐슬)와 지역(광주)에 대한 연결이 비어 있다.
그 두 가지를 채우는 게 이번 작업의 핵심이다.

■ 절대 규칙

1. 제출 매수 11장 고정이다. 페이지를 늘리지도 줄이지도 마라.
2. 페이지 구조를 재편하지 마라. 의뢰서에 명시된 것만 고친다.
3. 품번, 치수, 소재는 의뢰서에 명시된 것 외에는 건드리지 마라.
   규격 수치는 사내 Proludic 카탈로그에서 그대로 옮긴다. 추정 금지.
4. 롯데건설·Proludic 상표와 로고 형태는 바꾸지 마라.
5. 「아시아 최초」는 유지한다. 빼거나 완화하지 마라.
6. 책임·보증·손해배상 문구는 넣지 마라.
   인증 통과나 하자보수는 납품자가 계약상 당연히 지는 의무이지
   제안 조건이 아니다.

■ 작업 순서

1) 오탈자 8건, 영문·외래어 표현 5건 치환
2) 2-2BL 수치를 64명/45개로 통일, 표지에 3개소 합계 배지 신설
3) p7·p10 블록 라벨을 2-1BL / 2-2BL로 구분
4) 레이아웃 결함 수정
   - p8의 중복 STORY CONCEPT 텍스트 박스 제거
   - p8 DESIGN CONCEPT를 4개에서 3개로
   - 도면 범례와 번호 1:1 대조
5) 제품명 표기 통일
   - Kanope → Kanopé,  Kairm → Kairn
   - J984(Woodland/Woodwind), "6 flat seats"는 카탈로그 확인 후 통일
   - 소재코드(3SCD6 / 3SSCD6) 카탈로그 확인 후 전 페이지 통일
6) 슬로건을 THE FIRST CASTLE 하나로 통합,
   3개소를 FOREST / CHALLENGE / OCEAN CASTLE로 네이밍,
   "Play the Tomorrow" 전량 삭제
7) 지역 서사(무등산→광주천→영산강→바다)를 p3에 삽입
8) 컨셉 키워드를 블록당 6개에서 3개로.
   STORY CONCEPT 3단계를 키워드로 승격하고
   WOW / ACTIVE PLAY / PLAY FLOW / SYMBOL은 삭제
9) 「아시아 최초」 노출을 표지·p3·푸터 3곳으로 확대,
   p2 "55개국 150,000개소"와 한 문장으로 묶기
10) 푸터 띠 11장 중 8장을 정보로 전환
11) 2-2BL 마스터플랜(p11) 하단에 시설물 규격 띠 신설
    1BL p6, 2-1BL p9 상세 페이지는 그대로 둘 것
    Tree Frog가 1BL과 중복이므로 2-2BL은 해양 기구로 교체

■ 출력

1. 수정된 제안서 원고 (페이지별)
2. "변경 전 → 변경 후" 대조표
3. 의뢰서 검수 기준 체크 결과
4. 카탈로그로 판단이 안 된 항목

■ 판단이 필요하면

임의로 정하지 말고 물어봐라. 특히 제품 정식명, 소재코드, 규격 수치는
카탈로그에 없으면 비워두고 보고하라.
