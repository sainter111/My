첨부한 「AI 수정 의뢰서」대로 제안서 수정 원고를 작성해라.

■ 먼저 할 것

의뢰서를 처음부터 끝까지 읽어라. 요약하거나 건너뛰지 마라.
아래 작업 순서는 목차일 뿐이고, 실제 수정 내용과 치환 문자열은
전부 의뢰서 본문에 있다. 의뢰서에 있는 항목을 하나도 빠뜨리지 마라.

■ 상황

프랑스 놀이시설 브랜드 Proludic의 한국 독점 수입사가
롯데건설에 내는 「광주중앙 1BL·2-1BL·2-2BL 조경놀이(외산) 디자인공모」
제안서다. 현행 11장. 경쟁 PT다.

원안은 Proludic 프랑스 본사가 만든 것이라
제품과 디자인은 좋지만 발주처(롯데캐슬)와 지역(광주)에 대한 연결이 비어 있다.
그 두 가지를 채우는 게 이번 작업의 핵심이다.

■ 네가 만들 결과물

디자인 파일을 직접 고치는 게 아니다.
디자이너가 그대로 보고 반영할 수 있는 수정 원고를 만든다.
"어느 페이지의 무엇을, 무엇으로 바꾸는지"가 명확해야 한다.

■ 절대 규칙

1. 제출 매수 11장 고정이다. 페이지를 늘리지도 줄이지도 마라.
2. 페이지 구조를 재편하지 마라. 의뢰서에 명시된 것만 고친다.
3. 품번, 치수, 소재는 의뢰서에 명시된 것 외에는 건드리지 마라.
   규격 수치는 사내 Proludic 카탈로그에서 그대로 옮긴다. 추정 금지.
4. 롯데건설·Proludic 상표와 로고 형태는 바꾸지 마라.
5. 「아시아 최초」는 유지한다. 빼거나 완화하지 마라.
6. 책임·보증·손해배상 문구는 넣지 마라.
   인증 통과나 하자보수는 납품자가 계약상 당연히 지는 의무이지
   제안 조건이 아니다.
7. 확신이 없으면 임의로 정하지 말고 그 항목을 표시해서 보고해라.

■ 작업 순서 (상세 내용은 의뢰서 참조)

1) 오탈자 치환                      → 의뢰서 1번
2) 외래어·영문 표현 교정             → 의뢰서 2번
3) 제품명·소재코드 표기 통일          → 의뢰서 2-1번
4) 2-2BL 수치 통일, 표지 합계 배지    → 의뢰서 3번
5) p7·p10 블록 라벨 구분             → 의뢰서 4번
6) 레이아웃 결함 수정                → 의뢰서 5번
7) 2-2BL 규격 띠 신설                → 의뢰서 6번
8) 슬로건 통합 + 3개소 캐슬 네이밍     → 의뢰서 7번
9) 지역 서사 삽입                    → 의뢰서 7-4번
10) 컨셉 키워드 6개→3개              → 의뢰서 8번
11) 「아시아 최초」 노출 확대          → 의뢰서 9번
12) 푸터 띠 전환                     → 의뢰서 10번

각 항목을 끝낼 때마다 무엇을 했는지 한 줄로 남겨라.

■ 출력 형식

1) 페이지별 수정 원고
   페이지마다 아래 형식으로. 바뀌는 것만 적는다.

   [p3]
   - 위치: 헤드라인
     현재: 하나의 롯데태슬 아이덴티티
     수정: 하나의 롯데캐슬 아이덴티티
   - 위치: 대제목
     현재: THREE PLAYSCAPES, ONE SIGNATURE
     수정: THREE CASTLES, ONE LOTTE CASTLE
   ...

2) 전체 변경 대조표 (한 표로 모아서)

3) 의뢰서 11번 검수 기준 전 항목 자체 점검 결과
   충족 / 미충족 / 해당없음으로 표시하고, 미충족이면 이유를 적어라.

4) 처리하지 못한 항목
   카탈로그가 필요한 것, 원본 파일을 열어봐야 아는 것,
   판단이 필요한 것을 구분해서 나열해라.

■ 하지 말 것

- 의뢰서에 없는 내용을 새로 제안하지 마라.
- 수치를 추정해서 채우지 마라.
- 페이지를 합치거나 나누지 마라.
- 잘 모르겠으면 넘어가지 말고 4)번에 적어라.
