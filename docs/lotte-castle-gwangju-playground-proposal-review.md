# 롯데캐슬 광주중앙 조경놀이(외산) 제안서 — 보완점 정리

> 대상: 「광주중앙 1BL·2-1BL·2-2BL 조경놀이(외산) 디자인공모」 제출본 11p
> 관점: Proludic France 한국 독점 파트너 ↔ 롯데건설 심사석

---

## 진단

**매력 100점, 안심 20점.**

디자인은 이미 통과선을 넘었다. 남은 과제는 하나다 —
**외산을 고른 심사위원이 짊어질 책임을 덜어주는 것.**

심사위원은 "프랑스 놀이터라 예쁘다"에 표를 주지 않는다.
"이걸 골랐다가 내가 책임질 일이 없겠다"에 표를 준다.

## 修 · 고친다 — 정확성

### 브랜드명 오타 ⚠️ 최우선

> p3 헤드라인 — *"하나의 **롯데태슬** 아이덴티티"*

심사위원은 자기 회사 브랜드명 오타를 100% 발견한다.
제안 내용과 무관하게 **"우리 브랜드를 존중하지 않는다"**로 읽힌다.

## 補 · 채운다 — 신뢰 (**실질 승부처**)

현행 11p = **컨셉 9p + 제품 2p.**
심사석 5인 중 **3인의 질문에 답이 없다.**

| 심사 주체 | 실제 속마음 | 현행 |
|---|---|---|
| 조경·설계 | 우리 마스터플랜과 붙나? | △ |
| 상품기획 | 이걸로 무슨 카피를 쓰지? | **✕** |
| 공무 | 프랑스산, 준공일 맞추나? | **✕** |
| CS·품질 | 부서지면? 부품은? 폭염엔? | **✕** |
| 안전·인허가 | KC 인증·설치검사 통과되나? | **✕** |

### 없는 5장

| 페이지 | 킬러 문장 |
|---|---|
| **안전 · 인증** | EN 1176 원성적서부터 국내 KC 안전확인과 설치검사까지 — **전 과정을 당사가 수행**합니다 |
| **공정 · 납기** | 준공 [OO]개월 전 발주 기준 확정 납기, **지체상금 조항을 수용**합니다 |
| **유지관리 · A/S** | 준공 후 놀이터 민원은 롯데건설이 아니라 **당사가 직접 받습니다** |
| **현장 시공조건** | 설계 확정 전 **구조도면을 선검토**합니다 — 설치 단계에서 "안 된다"는 말이 나오지 않도록 |
| **리스크 Q&A** | 우려하실 일곱 가지를 **저희가 먼저 말씀드립니다** |

> **+ 누락분: 2-2BL 시설물 상세**
> 1BL(p6)·2-1BL(p9)에는 있는데 2-2BL만 없다. 3개소 대칭이 깨져 눈에 바로 띈다.

### 숨은 승부처 — 지하주차장 상부

아파트 놀이터는 대부분 슬래브 위에 놓인다. 경쟁사가 놓치는 지점.
Kanopé 타워 **6.86m** — 슬래브 하중 · 토심 · 방수층 관통 · 풍하중.
여기를 선제적으로 다루면 **"실제 시공을 아는 업체"**가 된다.

### 리스크 Q&A 7종

| 우려 | 답변 축 |
|---|---|
| 인증 통과되나 | 전 과정 당사 수행, 불합격 시 전량 교체 책임 |
| 준공일 맞추나 | 확정 납기 + 지체상금 수용 |
| 부품 수급은 | 국내 상시재고, 교체 SLA [OO]일 |
| 지하주차장인데 되나 | 구조도면 선검토 + 저하중 기초 대안 |
| 아시아 최초면 미검증 아닌가 | 유럽 [OO]개소 [OO]년 실적 — **제품은 검증됐고, 아시아에 없을 뿐** |
| 여름에 뜨겁지 않나 | 저축열 소재 + 슬라이드 음영 배치 |
| 국산보다 비싸지 않나 | 단가 아닌 **LCC(내구연한 환산)**로 프레임 전환 |

## 換 · 바꾼다 — 각인

### 워딩: 7개 → 1개

현행 슬로건 일곱 개가 난립한다.
More Than Play / Play for Generations / Play for a Better Tomorrow /
Play the Tomorrow *(문법 오류, 삭제)* / Not just imported /
Different Experiences… / Asia First

**일곱 개를 다 말하면 0개가 남는다.**
그리고 어느 문구에도 **'롯데캐슬'이 놀이터와 의미적으로 결합되어 있지 않다.**
지금은 "프랑스 놀이터 + 롯데 로고"다.

### 롯데캐슬 = CASTLE

놀이터를 '성(城)'의 언어로 번역하면, 브랜드와 제품이 **단어 하나로 결합**된다.

```
          THE FIRST CASTLE
     아이가 처음 갖는, 자신만의 캐슬

   프랑스가 설계하고, 롯데캐슬이 완성합니다.

    THREE CASTLES, ONE LOTTE CASTLE
```

| 블록 | 현행 | 제안 | 한 줄 |
|---|---|---|---|
| 1BL | FOREST LANDMARK | **FOREST CASTLE** 숲의 캐슬 | 오를수록 넓어지는 세상 |
| 2-1BL | ACTIVE ADVENTURE | **CHALLENGE CASTLE** 도전의 캐슬 | 어제보다 한 칸 더 높이 |
| 2-2BL | OCEAN STORY | **OCEAN CASTLE** 바다의 캐슬 | 떠나지 않아도 항해가 시작된다 |

**왜 강력한가**
① 심사사 브랜드명이 컨셉의 **구조 자체**가 된다 → 경쟁사 복제 불가
② 그대로 **분양 카피로 전용 가능** → 상품기획팀이 즉시 반응
③ 네이밍 통일만으로 "One Design Language" 주장이 **스스로 증명**된다

### Asia First 방어

"아시아 최초"는 차별화이자 동시에 **"검증 안 됨" 리스크**다.
심사석에서 100% 나오는 질문. 반드시 세트로 쓴다.

> **ASIA FIRST, NOT FIRST TIME**
> 아시아에서는 처음이지만, 세계에서는 처음이 아닙니다.

### 두 장의 카드

**① AERIAL SIGNATURE — 위에서 볼 때 완성되는 놀이터**

아파트 놀이터는 땅에서 보는 시간보다 **내려다보는 시간이 길다.** 전 세대의 창밖 풍경이다.
그런데 현행 제안서는 이걸 p10에서 우연히 보여주기만 하고 개념화하지 않았다.

> *"1층에서는 놀이터이고, 15층에서는 풍경입니다."*

상품기획팀이 즉시 쓸 카피 · 국내 업체가 하지 않는 말 · 이미 가진 렌더로 **추가 비용 0원**.

**② 지역성 — 무등산에서 바다까지**

2-2BL 해양 테마는 내륙도시 광주와 고리가 약하다. *"왜 광주에 바다?"*에 답이 없다.
제품은 그대로, 스토리만 잇는다.

> **무등산 → 광주천 → 영산강 → 바다**
> 1BL의 숲에서 시작해 2-2BL의 바다에서 끝나는 하나의 여정

지역성 방어와 3개소 연결 서사가 **한 번에 해결된다.**

## 작성 시 주의

1. **`[OO]` 수치는 전부 실제 값으로.** 납기 주수, 인증 소요기간, 보증 연한, 부품 SLA, 유럽 실적 — 본사 및 국내 인증기관 확인 후 기재.
2. **인증 절차는 사전 확인 필수.** 「어린이제품 안전 특별법」·「어린이놀이시설 안전관리법」 적용 범위는 품목·구조에 따라 다르다.
3. **지체상금 수용 · 민원 직접 응대는 사내 승인 후.** 제안서에 쓰는 순간 계약 조건이 된다.
4. **국산 비교표는 공개 객관 자료만.** 롯데건설도 국내 업체와 거래한다.
5. **무등산 등 지역 언급은 실제 대지 조건 확인 후.** 틀리면 역효과가 크다.
6. **Proludic 본사 CI 규정 준수** — 슬로건 변형·병용 시 본사 사전 승인 권장.
