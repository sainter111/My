# 매수 제약 재구성 — 11장 안에서 이기는 법

> 전제: **제출 매수 11장 고정 · 별첨/부록 불허**
> → 5장 추가는 불가능하다. 문제를 **"추가"에서 "교환"**으로 바꾼다.

---

## 원칙

이것은 **디자인공모**다. 비주얼을 과하게 깎으면 본전을 잃는다.
따라서 순서가 중요하다.

```
① 공짜 공간부터 회수한다   (0장 소모)
② 중복 페이지를 통합한다   (3장 회수)
③ 그래도 모자라면 교환한다  (최후)
```

---

## 1단계 · 공짜 공간 회수 — 0장 소모

### 기법 1. 푸터 띠를 정보로 전환 ★ 가장 큰 회수

현행은 **11장 전부** 하단에 같은 문장이 반복된다.

> *Different Experiences. One Design Language. One Lotte Castle.*
> *서로 다른 경험을 하나의 디자인 언어로 연결한 롯데캐슬의 새로운 플레이스케이프.*

띠 높이 × 11장 = **실질 1장 분량.** 같은 문장을 열한 번 읽는 사람은 없다.

| | 현행 | 개선 |
|---|---|---|
| p1 · p3 · p11 | 슬로건 | **슬로건 유지** (첫 장·개요 장·마지막 장만) |
| p2 | 슬로건 | EN 1176 · KC 안전확인 · 설치검사 — **인증 전 과정 당사 수행** |
| p4·p6·p8 | 슬로건 | 프랑스 본사 설계 · Vouvray 자체 생산 · **아시아 최초 도입 기종** |
| p5·p7·p9 | 슬로건 | 소모품 국내 상시재고 · 교체 SLA [OO]일 · **연 [OO]회 무상점검** |
| p10 | 슬로건 | 준공 [OO]개월 전 발주 기준 **확정 납기 · 지체상금 수용** |

> 슬로건은 **세 번만 나올 때 각인된다.** 열한 번 나오면 배경이 된다.

### 기법 2. 표지 숫자 배지 = Executive Summary 대체

단독 요약 페이지를 만들지 않고 표지 하단에 배지 한 줄.

```
3 SITES · 1,105㎡ · 195명 · 148 PLAY FUNCTIONS · ASIA FIRST
```

### 기법 3. p2 「Premium Materials & Safety」 칸 확장

현행 4대 차별성 중 세 번째 칸이 *"HPL, 스테인리스, 로프, WPC 동 / 유럽 안전기준에 기반한 품질"* 한 줄이다.
이 칸을 **안전·인증 블록으로 확장**한다. 페이지 소모 0.

```
EN 1176 · EN 1177   본사 시험성적서 원본 보유
KC 안전확인          「어린이제품 안전 특별법」
설치검사             「어린이놀이시설 안전관리법」
→ 성적서 확보 · 인증 신고 · 설치검사 대응 전 과정 당사 수행
→ 불합격 시 전량 교체 및 재검사 비용 부담
```

### 기법 4. 시설물 감성 카피 21개 삭제

현행 p6·p9의 기구마다 붙은 *"자연 속 친구들과 함께하는 균형 놀이"* 류 카피.
**심사 가치는 낮고 지면은 많이 먹는다.** 전량 삭제 → 규격표 압축 배치 가능.

---

## 2단계 · 통합 — 3장 회수 ★ 핵심 수술

**시설물 상세 페이지를 없애고, 각 블록 마스터플랜 페이지 하단 띠로 흡수한다.**

현행 p5·p8·p11 마스터플랜 페이지에는 이미 기구 **번호-명칭 범례**가 있다.
여기에 **썸네일 + SIZE + MATERIAL** 2줄만 얹으면 상세 페이지가 불필요해진다.

```
회수: p6 (1BL 상세) + p9 (2-1BL 상세) + 미제작 2-2BL 상세  =  3장
부수 효과: 2-2BL 비대칭 문제 동시 해결
```

**마스터플랜 페이지 하단 띠 규격**

```
┌─────────────────────────────────────────────────────┐
│ ① Kanopé Multiplay Unit J56011                      │
│    [썸네일]  14.43×8.97×6.86m                        │
│              GI ST Pipe, HPL, Recycled PE/AL, …      │
│ ② Mini Rope Hammock Swing J443  … (7종 가로 배열)     │
└─────────────────────────────────────────────────────┘
```
> 감성 카피 없음. 썸네일 소형. **규격만.** 심사위원이 확인하려는 것은 치수와 소재다.

## 3단계 · 최종 배치

### ◎ A안 — 권장

```
p1   표지  + 숫자 배지                    [Executive Summary 겸]
p2   WHY PROLUDIC + 안전 · 인증            [기법 3 적용]
p3   THREE CASTLES 개요 + ASIA FIRST 방어
p4   1BL   컨셉
p5   1BL   마스터플랜 + 시설물 규격 띠
p6   2-1BL 컨셉
p7   2-1BL 마스터플랜 + 시설물 규격 띠
p8   2-2BL 컨셉                          [AERIAL SIGNATURE 캡션 흡수]
p9   2-2BL 마스터플랜 + 시설물 규격 띠      ← 대칭 회복
p10  공정·납기 + 유지관리·A/S + 현장 시공조건
p11  리스크 Q&A                          ← 마지막 장 고정
```

| | |
|---|---|
| **획득** | 신뢰 페이지 2장(p10·p11) + p2 절반 + 푸터 8줄 + 2-2BL 대칭 회복 |
| **손실** | 시설물 감성 카피, 대형 제품 단독컷 |
| **비주얼** | 3개소 × 2장 = **6장 유지** — 디자인공모의 본체는 그대로 |

### ○ B안 — 신뢰 우선 (권장하지 않음)

```
p1 표지 │ p2 WHY+안전·인증 │ p3 개요
p4 1BL 통합 │ p5 2-1BL 통합 │ p6 2-2BL 통합   (컨셉+마스터플랜+시설물 각 1장)
p7 AERIAL SIGNATURE + 분양 활용
p8 공정·납기 │ p9 유지관리·A/S │ p10 현장 시공조건
p11 리스크 Q&A
```

신뢰 4장을 얻지만 **비주얼이 3장으로 줄어든다.** 디자인공모에서는 위험하다.
→ *경쟁사가 디자인만 들고 온다는 정보가 확실할 때에만* 유효.

## 4단계 · p10에 3주제를 담는 법

**3단 세로 분할.** 각 단 하단에 킬러 문장 1줄.

```
┌──────────────┬──────────────┬──────────────┐
│ 공정 · 납기    │ 유지관리·A/S   │ 현장 시공조건  │
│              │              │              │
│ 역산 간트      │ 교체 SLA 3단  │ 슬래브 단면도  │
│ 7단 축약      │ 보증 3단      │              │
│              │              │ 제약→대안 3쌍  │
│ 버퍼 3종       │ 연[OO]회 점검 │              │
│ (아이콘만)     │ 창구 분리     │ 선(先)검토    │
├──────────────┼──────────────┼──────────────┤
│ 지체상금 수용  │ 민원, 저희가   │ 설계 확정 전   │
│              │ 받겠습니다     │ 구조도면 검토  │
└──────────────┴──────────────┴──────────────┘
```

> 좌·중·우 세 단이 각각 **공무팀 · CS팀 · 설계팀**에게 보내는 메시지다.
> 한 장이지만 읽는 사람은 자기 단만 본다. 그래서 통합이 가능하다.

## 5단계 · p11은 절대 통합하지 말 것

리스크 Q&A는 **마지막 장 단독 유지.** 심사위원이 제안서를 덮으며 남는 잔상이다.

**지면 확보 방법** — 앞서 설계한 4열 표에서 **「근거」 열을 삭제**하고
답변 칸에 숫자를 직접 박는다. (어차피 참조할 별도 페이지가 없어졌다)

| 우려하실 점 | 당사 답변 |
|---|---|
| 국내 인증, 통과되나? | EN 1176 성적서 · KC 안전확인 · 설치검사 **전 과정 당사 수행** / 불합격 시 전량 교체 |
| 준공일, 맞출 수 있나? | 준공 [OO]개월 전 발주 기준 확정 납기 / **지체상금 조항 수용** |
| 부품 수급은? | 소모품 국내 상시재고 / 교체 [OO]일 · 긴급 [OO]시간 출동 |
| 지하주차장 위인데 되나? | 설계 확정 전 **구조도면 선검토** / 저심도·무관통 기초 대안 보유 |
| 아시아 최초면 미검증 아닌가? | 유럽 [OO]개소 · [OO]년 운영 / **제품은 검증됐고, 아시아에 없을 뿐** |
| 여름에 뜨겁지 않나? | 저축열 소재 · 슬라이드 음영 배치 · 표면온도 관리 |
| 국산보다 비싼 것 아닌가? | 단가 아닌 **LCC(내구연한 환산)** / 교체주기 반영 시 역전 |

> ## 저희가 먼저 말씀드리는 이유는,
> ## 이 답변들을 계약서에 넣을 준비가 되어 있기 때문입니다.

## 의도적으로 버리는 것

매수 제약은 **무엇을 버릴지 정하는 일**이다. 아래는 버려도 되는 것들이다.

| 버리는 것 | 이유 |
|---|---|
| 시설물 감성 카피 21개 | 심사 배점에 영향 없음 |
| 대형 제품 단독컷 | 썸네일로 충분 — 규격이 본질 |
| Executive Summary 단독 장 | 표지 배지로 흡수 |
| AERIAL SIGNATURE 단독 장 | p8 2-2BL 컨셉이 이미 조감 렌더 → **캡션 한 줄로 흡수** |
| 국산 대비 LCC 비교표 | p11 Q&A 7번 행 한 줄로 축약 |
| One Design Language 증거 장 | p3 개요에 컬러·사인 스트립으로 흡수 |
| 인클루시브 · 야간경관 | **구두 PT로** — 제안서에서 제외 |

### 분양 카피 세트는 PT에서 구두로

제안서에 넣을 자리가 없다. 대신 **PT 마무리 30초**에 말로 전달한다.

> *"마지막으로, 저희 제안을 채택하시면 이 이름들을 그대로 쓰실 수 있습니다.
> 숲의 캐슬, 도전의 캐슬, 바다의 캐슬. 그리고 —
> **아이의 첫 번째 캐슬은, 집 앞에 있습니다.**"*

페이지를 쓰지 않고 상품기획 담당에게 도달하는 유일한 경로다.

## ⚠️ 제출 전 반드시 확인할 것

공모 지침을 다시 보셔야 할 항목이 있습니다. **한 장을 더 벌 수도 있습니다.**

1. **표지·목차가 매수에 포함되는가** — 제외라면 **1~2장 여유**가 생긴다. 가장 먼저 확인할 것.
2. **양면 인쇄 시 매수 산정 기준** — 장(sheet)인지 면(page)인지.
3. **별첨 불허의 범위** — '제출물'에 한정인지, PT 자리에서 건네는 참고자료까지인지.
4. **페이지 규격** — A3 가로 허용 여부. 허용된다면 p10 3단 분할이 훨씬 수월하다.

> 1번이 "표지 제외"로 확인되면 **A안에 AERIAL SIGNATURE 또는 안전·인증 단독 장을 복원**할 수 있다.
