# 확인 대기 항목 — 2차 반영분

> 1차 수정본에는 **넣지 않는다.** 확인이 끝난 뒤 2차에서 반영한다.
> 추정치를 쓰면 계약 후 책임이 되므로, 확인 전에는 해당 내용을 아예 빼고 간다.

---

## ① 프랑스 본사 — 8건

| 확인할 것 | 현황 | 2차에 쓰일 곳 |
|---|---|---|
| J984 정식 제품명 | p5 `Woodwind Seesaw` / p6 `Woodland Seesaw` 불일치 | 규격 띠 |
| 소재 코드 | p6 `3SCD6 ST` / p9 `3SSCD6 ST` 불일치 | 규격 띠 전체 |
| `6 flat seats` 정식 제품명 | 혼자 소문자 설명형, 타 제품은 Title Case | 규격 띠 |
| Tree Frog 대체 해양 기구 | 1BL·2-2BL 중복 배치 | 2-2BL 규격 띠 |
| 제품 이름의 뜻 (Kanopé / Kairn / Aquatica) | 어원 스토리를 쓰려면 본사 의도 확인 필요 | 각 블록 컨셉장 |
| **3개 기종 아시아 미설치 확인서** | 「아시아 최초」의 근거 | p3 배너 하단 |
| 유럽 동일 기종 설치 개소수 · 운영 연수 | "검증 안 된 것 아니냐"에 대한 답 | 예상질문 |
| 본사 발주 부품 소요 주수 | A/S 답변의 핵심 숫자 | 공급 체계 |

> 🔴 **아시아 미설치 확인서가 최우선.** 제안서 최대 차별점인데 현재 근거가 없다.
> 품번까지 적으면 사실이 아닐 때 더 위험해지므로, 확인 전에는 근거 문구를 넣지 않는다.

## ② 국내 인증기관 — 1건

| 확인할 것 | 비고 |
|---|---|
| 인증 단계별 소요기간 | KC 안전확인 신고~취득, 설치검사 신청~합격 |

> 「어린이제품 안전 특별법」·「어린이놀이시설 안전관리법」 적용 범위가
> 품목·구조에 따라 달라 기관 직접 확인이 필요하다.

## ③ 물류 · 시공 — 1건

| 확인할 것 | 확인처 |
|---|---|
| 리드타임 (본사 생산 / 선적 / 통관·내륙운송 / 현장 설치) | 포워더 · 관세사 · 국내 시공팀 |

> ②+③이 합쳐져야 **"준공 몇 개월 전 발주"**가 나온다.
> 납기 역산표는 이 숫자가 없으면 만들 수 없다.

## ④ 사내 — 1건

| 확인할 것 | 비고 |

## 2차에 추가할 내용

확인이 끝나면 아래를 넣는다.

|---|---|
| 준공일 역산 일정표 (발주 → 생산 → 선적 → 통관 → 설치 → 검사) | ② + ③ |
| 예상 질문 페이지의 숫자 답변 | ① ② ③ ④ |
| 「아시아 최초」 근거 품번 병기 | ① |
| 제품명 어원 스토리 | ① |
| 제품명 · 소재코드 최종 통일 | ① |
| 지하주차장 상부 기초 검토 | ⑤ |

## 본사 메일 — 한 통에 묶어서

①의 8건은 **메일 한 통으로 같이 물으면 된다.** 시차가 있으니 가장 먼저 발송.

```
문의 항목
1. J984 — Woodland Seesaw / Woodwind Seesaw 중 정식 명칭
2. 소재 코드 — 3SCD6 ST / 3SSCD6 ST 중 정확한 표기
3. J483 "6 flat seats" — 정식 제품 명칭
4. Tree Frog's Springer 대체 가능한 해양 테마 동급 기구
5. Kanopé / Kairn / Aquatica — 제품 네이밍의 유래와 의도
6. J56011 Kanopé / J6102 Kairn / Aquatica — 아시아 지역 설치 이력 유무
   (없을 경우 확인서 형태로 회신 요청)
7. 위 기종의 유럽 내 설치 개소수 및 최장 운영 연수
8. 소모성 부품 발주 시 표준 납기 (주 단위)
```

> 6번은 **문서로 남는 형태**로 받아야 한다. 제안서에 근거로 인용할 항목이다.
